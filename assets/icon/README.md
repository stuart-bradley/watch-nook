# Watchnook — app icons

Concept **2a** (play triangle inside a cozy nook arch), **Honey · gold (D5)** tint —
dark glyph `#3A2A00` on honey `#E9BF64`, matching the app's primary.

## Files

| File | Purpose |
|------|---------|
| `ic_launcher.png` (1024) / `.svg` | Full-bleed rounded icon — iOS & legacy Android, store listing |
| `ic_foreground.png` (432) / `.svg` | Adaptive **foreground** — glyph only, transparent, inside the 66dp safe zone |
| `ic_background.svg` | Adaptive **background** — solid honey (config uses the hex directly) |
| `ic_launcher_monochrome.png` (432) / `.svg` | Android 13+ **themed** icon layer (black on transparent; system tints it) |
| `ic_notification_*.png` | Status-bar / notification icon — **white on transparent**, per density (mdpi→xxxhdpi) |

## Wiring

Launcher/adaptive icons are generated by `flutter_launcher_icons` — see
`../flutter_launcher_icons.yaml`. Run from the `flutter/` dir:

```
dart pub add --dev flutter_launcher_icons
dart run flutter_launcher_icons
```

The **notification** icon is not managed by that tool. Copy each
`ic_notification_<density>.png` to the matching `android/app/src/main/res/drawable-<density>/ic_notification.png`,
then reference it:

- `flutter_local_notifications`: `AndroidInitializationSettings('ic_notification')`
- FCM manifest: `<meta-data android:name="com.google.firebase.messaging.default_notification_icon" android:resource="@drawable/ic_notification"/>`

Android draws notification icons as a **silhouette** — only the alpha matters,
which is why these are pure white. The status bar tints them automatically.

## Regenerating / re-tinting

All PNGs are rendered from the SVG masters. To switch tint (e.g. to another
palette) change the two hex values at the top of the generator and re-render;
the notification/monochrome layers are colour-independent (alpha only).
